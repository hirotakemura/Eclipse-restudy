# デザイン参考ナレッジ

**目的：** 「格好いいサイト」を眺めて終わりにせず、**我々の語彙（surface / layout / hero / motif / media / motion / presentation）に翻訳して積む。**
翻訳できないものは、参考にならない。テンプレートは1つしか持たない（D-096）ので、

## 記録のルール

> **見ていないものを書かない。**
>
> 各エントリには「**誰が・いつ・何を見て**書いたか」を必ず入れる。
> 画面を見ずに属性だけを見て「実測」と書き、2件を誤報した前科がある（D-228）。
> **推測で書いた行は、あとから区別がつかなくなる。**

各参考サイトについて、**次の9項目を必ず埋める。** 埋まらない項目は「未確認」と書く。

| 項目 | 何を見るか |
|---|---|
| 1. 写真の依存度 | **その絵は写真が無くても成立するか。** 全画面写真が主役なら、我々には移植できない |
| 2. 明暗 | 暗い面を使っているか。使っているなら、どの帯で |
| 3. 型の大きさ | 見出し・本文のpx。とくに**いちばん大きい文字** |
| 4. 幅 | コンテナの最大幅。全幅の帯があるか |
| 5. 縦のリズム | 帯と帯の間隔 |
| 6. 色数 | アクセントは何色か。無彩色との比 |
| 7. 動き | 何が動くか。止めても成立するか |
| 8. 情報表現 | 我々の12個（prose/list/chips/cardGrid/largeNumber/spec/comparison/timeline/process/quote/longform/fullWidth）のどれに当たるか。**当たらないものは、増やす価値があるか** |
| 9. 材料 | その見せ方に必要な材料を、**我々の取材74項目で集められるか。** 集められないなら絵に描いた餅 |

最後に必ず1行：**「これを我々の案件で再現するには、何が足りないか」**

### 決定済み② 暗い面を解禁する（2026-09-14・D-230）

D-199 は「暗い背景は作らない」。理由は**コントラスト検査が実質2倍になり、
6配色すべてに暗色面の定義が要る。効果より手数が勝つ**。
Industrial 系は暗い面を使うことが多く、**参考例とこの決定は正面からぶつかる。**

**解禁した。** ただし**新しい色は1つも足していない。**
暗い地は `--ink`（本文の色）をそのまま使う。白文字で 15.9〜18.4:1（6配色すべて）。
検査は84件→102件。`--accent` を暗い地の上の文字に使うと 1.1〜2.9:1 で読めないため、
**使用禁止であることも検査に書いた**（読めてしまったら前提が変わったということ）。

使うのは **量産・設備**と**製品・開発**の2つの型で、**1ページに1回、lead の帯にだけ**（D-231）。
残る4つの製造業向けの型（標準・精密加工・老舗職人・設計技術）は明るいまま。
