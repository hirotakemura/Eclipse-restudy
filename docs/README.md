# docs の索引

**番号は変えない。** コードのコメントから `docs/31 原則⑤` のように**番号で参照している箇所が
78ある**ので、並べ替えやフォルダ分けをすると、**同じ対応表が2箇所にできてずれる**（D-197）。
分類はこの索引の中だけで行う。

**状態**の意味：
　**現役** … いま運用で使う（読んで、そのとおりに動かすもの）
　**記録** … 決めた経緯。変えないが、消しもしない
　**仮値** … 社長が仮の値を置いてある（D-365）。**契約と請求には使えない。** 確定値が出たら差し替える
　**未決** … まだ決まっていない論点が残っている
