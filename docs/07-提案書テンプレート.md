## 2枚目：現状診断 ★ここで勝負が決まる

**提案書の成否の8割はこの1枚で決まる。** 一般論を書いた瞬間に、他社の提案書と同じ束に入る。

必ず入れる要素：

```
■ 検索での見え方
　「{{材質}} {{加工法}} {{地域}}」月間検索数 {{n}}回 → 御社は現在 圏外（50位以下）
　1位は {{競合社名}} 様。同社のサイトには {{事例数}}件の加工事例が掲載されています。

■ スマートフォンでの表示
　現行サイトはスマホ対応がされておらず、文字が読めない状態です。
　{{業界}}の調達担当者の {{n}}割はスマホでも検索します。

■ 表示速度
　トップページの表示に {{n}}秒かかっています（Google推奨は2.5秒以内）。
　3秒を超えると訪問者の約半数が離脱するとされています。

■ 掲載されていない情報
　・対応可能な材質・サイズ・精度の記載がありません
　・保有設備の型番が記載されていません
　・加工事例が掲載されていません
　→ 調達担当者が発注先を選ぶ際に最も見る情報が、すべて欠けています。
```

> **この1枚のために、商談前に必ず検索調査と現行サイトの計測を行う。** 30分の作業で受注率が変わる。

## 3枚目：機会損失の試算

課題を「感覚」から「金額」に変える。決裁者が稟議を通すための材料。

```
　「{{キーワード}}」の月間検索数　　　　　　　{{n}}回
　うち具体的な発注検討層（仮に3%）　　　　　　{{n}}件/月
　現在、御社に届いている数　　　　　　　　　　0件

　御社の1件あたり平均取引額　　　　　　　　　{{金額}}円（取材時ヒアリング）
　年間の機会損失（推計）　　　　　　　　　　　{{金額}}円
```

> 数字は必ず**控えめに**置く。盛った試算は製造業の社長にすぐ見抜かれ、逆に信用を失う。前提条件も明記する。

## 5枚目：御社の作業時間は約4.5時間です ★最大の差別化

**この1枚を提案書で一番大きく、一番目立つデザインにする。**

```
　　　　　制作期間中、御社にお願いする作業は これだけ です

　　　　　キックオフ　　　　　　　　 30分
　　　　　取材（1回のみ）　　　　　　 90分
　　　　　原稿・デザインのご確認　　　60分
　　　　　写真のご手配　　　　　　　　30分
　　　　　検収・公開前のご確認　　　　60分
　　　　　─────────────────────────────
　　　　　合計　　　　　　　　　　 約4.5時間

　　　　　原稿は、すべて弊社が執筆します。
　　　　　「原稿をご用意ください」とは申し上げません。
```

添えるコメント：

> Web制作が途中で止まる原因の大半は、原稿が揃わないことです。本業が忙しい中で、自社の技術を文章にまとめるのは簡単ではありません。
> 弊社は90分の取材で必要な情報をすべておうかがいし、原稿を執筆します。だから4週間で公開できます。

## 7枚目：お見積り

```
　■ Webサイト制作　　　　　　　　　　　　　　　　980,000円（税別）
　　　取材・構成設計・原稿執筆・デザイン・実装・公開
　　　スマートフォン対応／SEO基本設定／お問い合わせフォーム
　　　Googleビジネスプロフィール設定／公開後30日間の無償修正

　■ 運用パートナー契約　　　　　　　　　　　 月額 100,000円（税別）
　　　保守・更新／月1本の技術記事執筆／アクセスレポート／改善提案

　────────────────────────────────────────────────────
　■ 小規模事業者持続化補助金をご利用の場合（補助率2/3・上限200万円）

　　　制作費 980,000円 → 実質ご負担額 約 327,000円
　　　※ 申請書類の作成は弊社がサポートいたします（無償）
```

**補助金の行は必ず入れる。** 98万が33万に見えた瞬間、稟議の難易度が変わる。申請サポートを無償で付けるのは、それ自体が強力な差別化になるため。

### 値引き要求への対応方針（社内ルール）

**金額は下げない。スコープを下げる。**

> 「ご予算に合わせるため、ページ数を10ページから6ページに絞る形でしたら {{金額}}円でご提案できます。ただし加工事例のページは残させてください。ここが一番問い合わせに繋がる部分ですので。」

一度値引きすると、その顧客は運用費も値切られ、永久に不採算になる。**値引きで取った客は、値引きでしか続かない。**

## 9枚目：よくあるご質問

```
Q. 途中で内容を変更できますか
A. デザイン確定前であれば何度でも。確定後の大幅な変更は別途お見積りとなります。

Q. 公開後、自社で更新できますか
A. できます。WordPressを採用しますので、ブログを書く感覚で更新いただけます。
   操作説明の動画もお渡しします。

Q. 他社に乗り換えることはできますか
A. できます。データはすべて御社の所有物としてお渡しします。
   弊社でしか触れない作りにはいたしません。

Q. 写真は自社で用意が必要ですか
A. 「何をどう撮るか」の指示書を弊社が作成します。
   スマートフォンで撮影いただける部分と、プロ撮影を推奨する部分を分けてご案内します。

Q. 運用契約は必須ですか
A. 必須ではありません。ただし公開しただけのサイトはほぼ成果が出ません。
   問い合わせが増えるのは、公開後の改善を続けた場合です。
```

> **「他社に乗り換えられます」を自分から書く。** 製造業の社長が最も警戒しているのは業者ロックイン。ここを先に潰すと一気に警戒が解ける。ロックインしないと続かない事業には、そもそもしない。
