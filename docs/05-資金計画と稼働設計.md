## 0. 確定した前提が、計画をどう変えたか

アドバイザーの回答で最も重要だったのは **「副業である」** こと。
これにより **生活費を事業から捻出する必要がない。** この事業の最大のリスクだった「キャッシュが尽きて条件の悪い案件を取らざるを得なくなる」シナリオが、ほぼ消えた。

結果として方針を2点変更する：

1. **必要運転資金を大幅に引き下げられる。** 前版で「100万以上あれば元請けを狙える」と書いたが、副業前提なら **60万で足りる。**
2. **下請け案件の優先度を下げる。** 前版では「キャッシュ確保のための血液」と位置づけたが、生活費の圧力がないなら、下請けは**単価も実績価値も低い時間の切り売り**でしかない。週15時間という希少な資源を、下請けに使うのは損。
   → **下請けは「元請けが取れない期間の保険」として温存し、初月から取りには行かない。**

## 1. 事業主体の提案（Q-001への回答）

### 結論：個人事業として開業し、インボイス登録は初月から行う。合同会社化は後回し。

| | 判断 |
|---|---|
| **開業形態** | 個人事業（開業届のみ・費用0円・即日）|
| **インボイス（適格請求書発行事業者）登録** | **初月に必須で行う** |
| **法人化のタイミング** | 年間利益600万が見えた時点、または「法人でないと取引しない」相手に当たった時点 |

### なぜ最初から法人化しないか

合同会社設立は約10万円＋2〜3週間かかる。副業・週15時間の立ち上げ期に、この現金と時間を先に使う理由がない。合同会社→株式会社も、個人事業→法人も、後から移行できる。**先に作るべきは会社の箱ではなく、売れる商品と実績。**

### なぜインボイス登録は初月から必須か（ここは妥協できない）

顧客が **BtoB中小製造業＝ほぼ全てが課税事業者**だから。
インボイス未登録の請求書を出すと、顧客側が支払った消費税を控除できず、**実質10%の値上げと同じ**になる。「安いから未登録でいい」は通用しない。取引の前提条件。

あわせて **簡易課税制度**を選択する。Web制作はサービス業（第5種／みなし仕入率50%）。仕入がほとんど発生しない我々の原価構造では、原則課税より簡易課税のほうが有利かつ事務負担が軽い。
※ 選択には事前の届出が必要。**開業と同時に手続きする。**

### 副業として始める際の確認事項（アドバイザー側でご確認ください）

- 本業の就業規則で副業が禁止されていないか
- 住民税を「普通徴収」にできるか（本業への通知を避けたい場合）
- 事業所得として申告する前提（雑所得だと青色申告特別控除が使えない）

### 月次固定費（個人事業・1人）

> **負担者はアドバイザー（事業主）。友人には負担させない**（D-054）。
> 友人への支払いは成果報酬のみで、受注ゼロの月に持ち出しが出ない構造にする。
> ただし**営業に直接紐づく費用（DM印刷・郵送・交通費）は実費精算**で友人に返す。

| 項目 | 月額 |
|---|---|

| 通信・雑費 | 5,000円 |
| 営業費（DM・郵送・電話） | 30,000円 |
| **合計** | **約41,000円** |

> **前版の修正：** 月8〜10万としていたが、これは法人＋全ツール有料の前提だった。個人事業スタートなら **月4.1万**。
> **【2026-09-12 改訂】** 月額の保守料をいただかない方針に変えたため（D-056）、
> MRRを生存ラインとする考え方そのものを廃止した。
> 固定費は月41,000円で、**汎用案件1件の粗利（176,700円）だけで4ヶ月分が出る。**
> 生存ラインは実質的に問題にならない水準まで下がっている。

### 結論：必要資金

| ライン | 金額 | 内訳 |
|---|---|---|
| 最低ライン | **50万円** | 初期投資10万 + 固定費6ヶ月25万 + 制作原価10万 + 予備5万 |
| **推奨ライン** | **60〜80万円** | 上記＋撮影外注や急な機会への対応余力 |

副業のため生活費の持ち出しが不要。**80万あれば12ヶ月は余裕で戦える。**
もし現時点で50万を用意できない場合でも、**20万あれば Phase 1（自社サイト・提案書・実績づくり）は完走できる。** 営業費が本格的に必要になるのは Day 31 以降なので、そこまでに積み増す形でも成立する。

## 3. 週15時間をどう使うか（Q-002を受けた稼働設計）

**月あたり約65時間。これがこの事業の唯一の希少資源。**
私（社長）が制作・原稿・設計・文面作成を全て引き受けるので、アドバイザーの時間は**人間にしかできないこと**に全振りする。

### 月65時間の配分

| 用途 | 時間/月 | 内容 |
|---|---|---|
| 営業活動 | 30h | DMフォローコール、商談、紹介依頼 |
| 顧客対応 | 20h | 取材立ち会い、打合せ、検収 |
| 制作レビュー・確認 | 10h | 私が作ったものの確認と方向修正 |
| 事務・経理 | 5h | |

### 1案件あたりの人間側工数（実測前の見積）

| フェーズ | 時間 |
|---|---|
| 商談〜受注 | 4h |
| 取材 | 1.5h |
| 打合せ3回 | 3h |
| レビュー・検収 | 4h |
| **計** | **約12.5h / 件** |

→ 同時進行できる制作は **最大2件**。営業時間を確保すると **年間5〜7件が現実的上限。**

### 数値計画の引き直し（初年度）

> **【2026-09-12 改訂】この表の数字は、営業を友人が担当する体制変更で無効になった。**
> 本節の「1案件あたりの人間側工数 12.5h」も、商談が外れたため **8.5h** に変わっている。
> 詳細は `16-低単価多件数モデルの検討.md` 第6-2章。
>
> **件数と売上の計画値は置かない（D-050）。** 新しい上限は友人の営業量で、これは実績で測る。

| | 改訂後 |
|---|---|
| アドバイザーの1案件あたり工数（製造業） | **8.5h**（取材1.5h＋打合せ3h＋レビュー検収4h） |
| アドバイザーの1案件あたり工数（汎用） | **2.0h** |
| 年間の制作枠 | **720h**（営業30h/月が外れたため） |
| 月次固定費 | **4.1万**（アドバイザーが全額負担） |

売上見込みは下がったが、**固定費が半分以下になったので、事業としての安全性は上がった。**

### 時間の使い方で守るべき原則

1. **相見積もり・コンペには参加しない。** 勝率3割の案件に12時間使うのは、週15時間の体制では致命的。
2. **1商談あたり2時間を超えない。** 移動が必要な商談はオンライン化を打診する（製造業でもオンライン商談はもう普通）。
3. **見込みの薄い相手を早く切る。** 「予算がない」「今すぐではない」は追わない。リストに戻して半年後に再接触する。
