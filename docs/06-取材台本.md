# 取材台本 — 90分で全ページの原稿を書き切るための設計

作成: 2026-09-12 / 対象: BtoB中小製造業

---

## この台本の目的

**我々の商品の核心は「顧客に原稿を書かせないこと」。** 競合が「原稿をお待ちしています」で3ヶ月止まっている間に、我々は4週間で納品する。それを成立させる唯一の装置がこの取材。

**90分で、10〜15ページ分の原稿を書くだけの素材を取り切る。** 取材が失敗したら納期が崩れ、商品そのものが成立しない。ここが制作プロセスで最も重要な90分。

---

## 事前準備（取材の3日前まで）

### 【重要】地域の動きを調べてから行く

社長は、初対面の業者に取引先の事情を自分から話さない。
**「発注の先行きに変化はありますか」と一般的に聞いても何も出てこない。**

第1回モック取材では、**「日産の九州生産移管の話、影響ありますか」と具体的に振って初めて**
「今後読めない」という不安が出てきた。

→ **`12-北九州商圏戦略.md` 第2章（地域の産業の動き）を取材前に読み込み、こちらから振る。**
**調査は提案書のためだけでなく、取材の質を直接上げる。**

### こちらで入手しておくもの

- 現行サイトの全ページ（印刷 or スクショ）
- 会社案内パンフレット、製品カタログ、技術資料（PDFで送ってもらう）
- 会社概要（設立年・資本金・従業員数・主要取引先）
- **競合3社のサイト**（こちらで調査し、比較表を作っておく）
- **検索調査結果**：想定キーワードでの現在の順位、月間検索数

### 事前に送っておく質問（回答は不要、考えておいてもらうだけ）

> 当日おうかがいする内容です。**ご記入は不要です。**頭の片隅に置いておいていただければ大丈夫です。
>
> 1. 直近1年で新しく取引が始まったお客様は、どういうきっかけでしたか
> 2. 「この仕事はうちでないと無理だな」と思った案件はありますか
> 3. 本当はもっと受けたいけれど、今あまり来ていない仕事はありますか

※ **記入式のヒアリングシートは絶対に送らない。** それを送った瞬間、我々も「原稿を待つ制作会社」になる。

### 同席者の指定

- **社長（または後継者）は必須。** 会社の方向性を語れるのはここだけ
- **工場長・技術責任者も必須。**（2026-09-12 改訂：「いるとよい」から格上げ）
- Web担当者だけの取材は失敗する（会社の強みを語れない）

> **なぜ工場長が必須なのか（`15-第1回モック取材_検証結果.md`）**
>
> 社長ひとりへの取材では、**加工法・対応サイズ・対応精度・設備型番の4項目すべてが
> 「現場に聞かないと分からない」**になった。これは社長の落ち度ではない——
> 経営者が公差の管理値を暗記している必要はない。
>
> だが結果として、**BtoB製造業の検索を受け止める本体（材質×加工法×条件、設備型番）が空欄になる。**
> 技術ページが作れなければ、サイトを作る意味が半分なくなる。
>
> **同席できない場合は、別途30分の技術取材を必ず工程に組み込む。**
> あわせて**設備の銘板を写真撮影して型番を確定させる。** 口頭で聞いた型番は誤りが多く、
> 間違えると検索で拾われないうえ信用も落ちる。

### 誰が取材するか（2026-09-12 改訂）

**我々の側に製造業の専門知識がある人間はいません。** これを前提に組み立てます。

| 担当 | 役割 |
|---|---|
| **法人営業の経験者（友人）** | 主担当。聞く・引き出す技術はこの人が一番持っている |
| アドバイザー | 同席。記録とフォームへの入力 |
| 社長（私） | 取材には出られない。**代わりに台本と追い質問を用意する** |

> **分野知識は、人ではなく道具に持たせる。**
>
> 第1回モック取材で決定的だった「治具の内製」は、「薄物をどうやって押さえているんですか」
> という追い質問でのみ出ました。**この質問を思いつける人を探すのではなく、画面に出しておけばいい。**
>
> KOBOは取材中、ブロックごとに **「聞こえたら、そのまま掘る」** の一覧を常時表示します。
> 製造業に詳しくない取材者でも、相手の言葉に反応して掘れる状態にするのが目的です。

### 取材の回数（立ち上げ期は2回に分ける）

**最初から90分1回で取り切ろうとしないこと。**

| 時期 | 構成 |
|---|---|
| **立ち上げ期** | **1回目 60〜90分（会社・引き合い・強み・事例）／2回目 30〜60分（技術・設備／工場長同席）** |
| 慣れてから | 90分1回＋工場長30分 |

2回に分けても、**提案書で約束した「お客様の作業時間 約4.5時間」は守れます**（合計2〜2.5時間）。
守れないのは「4週間納期」のほうなので、**立ち上げ期は提案書の納期を6週間と書く**か、
2回目を1週間以内に設定して4週間に収めるかを、実測で決めます（`03` 第0章）。

## 当日の段取り（2026-09-13 追加）

### まずノートPC1台で始める。タブレットは必要になってから

**結論から言うと、第1回の取材はノートPC単体で足ります。**

| | |
|---|---|
| ノートPC単体 | `localhost` で動く。**ネットワークに一切出ない = 最も安全で、繋がらない問題も起きない** |
| ＋タブレット | 同じ網に出るため、その網にいる誰からも見える（D-078）。**設定の手間と事故の余地が増える** |

第1回は会議室で座って話す場面がほとんどです。**そこにタブレットは要りません。**
タブレットが効くのは、**第2回の技術取材で工場を歩くとき**だけです。

### 役割を分ける　★これが一番大事

**2人で行き、話す人と記録する人を分けます。**

| 担当 | 役割 |
|---|---|
| 友人（法人営業） | **話す。相手の顔を見る。追い質問をする。** 画面は見ない |
| アドバイザー | **記録する。** KOBOに入力し、未確認マークを押す |

> **取材中に画面ばかり見ていると、取材が下手になります。**
>
> 第1回モック取材で決定的だった「治具の内製」は、社長の「薄物は歪む」という一言を
> 拾って掘ったから出ました。**タイピングに気を取られていたら、聞き流していたはずです。**
>
> 聞くことと書くことを同じ人にやらせない。これが90分の質を決めます。

### 録音する。その場の入力は完璧でなくてよい

- **必ず録音する**（スマホのボイスメモで十分）。冒頭で一言断る
- 取材中の入力は**キーワードだけ**でよい。文章は後で録音を聞きながら整える
- **ただし「未確認」マークだけは、その場で必ず押す**

> 何を聞いて答えてもらえなかったかは、**後から思い出せません。**
> 録音を聞き直せば分かりますが、そのために90分を聞き直すのは現実的ではない。
> **押すのは2秒です。その場で押してください。**

### 場所はブロックによって変わる

| ブロック | 場所 |
|---|---|
| 1 会社の基本 ／ 2 引き合いの実態 | 会議室・応接室。座って話す |
| 3 技術・設備 | **工場を歩きながら。** 現物を見ながらのほうが具体が出る |
| 3後半 強み ／ 4 事例 | 会議室に戻る。落ち着いて掘る |
| 5 採用 ／ 6 クロージング | 会議室 |

**ブロック3で工場に出るときは、KOBOを閉じてカメラに持ち替えて構いません。**
設備の銘板を撮り、材質や加工法はメモして、**戻ってから入力する**ほうが確実です。

### 最後に、その場で確認していただく（2026-09-13 追加）

**ブロック6（クロージング5分）の最後に、KOBOの「入力を終える」を押します。**
聞き取った内容が読みやすい形で出るので、**画面をそのままお客様に向けます。**

```
　「入力を終える」を押す
　　↓
　自分用のメモが残っていないか、こちらで一度目を通す　←★ここを飛ばさない
　　↓
　「確認画面を開く」→ 画面をお客様に向ける
　　↓
　直すところがあれば「編集に戻る」→ その場で直す
　問題なければ「この内容で確認しました」→ 最初の画面に戻る
```

> **原稿を書いてから誤りが見つかると、作り直しになります。**
>
> 数字・型番・材質・社名の誤りは、**我々には検算しようがありません。**
> KOBOの安全装置（`lib/verify.ts`）が弾けるのは「どこにも書いていないことを書いた」
> 場合だけで、**聞き間違い・打ち間違いは弾けません。**
> その場で本人に見ていただくのが、唯一で最も安い検算です。

確認画面では、お客様にお見せできないものを自動で落としています。

| 出さないもの | 理由 |
|---|---|
| 充足率・消化率 | 我々の指標であって、お客様の資料ではない |
| 台本メモ・追い質問 | 同上 |
| 未確認欄に控えた発言 | 工場長に確認しにいくための手控え。確定した事実ではない |
| `{{要確認}}` 以降の文 | 我々への申し送り。確定した部分だけを見せる |
| 内部向けの見出し | 「強み（社長が自分では言えない部分）」を本人に向けるわけにいかない |

**ただし、自由記述欄に自分で書いたメモは機械では落とせません。**
「型番は社長の口頭記憶のため、現地で銘板と照合すること」のような書き方を
そのままお見せすることになるので、**開く前に一度目を通してください。**
確認画面を開く前に、その注意を出す画面を挟んであります。

未確認・未入力の項目は、隠さずに「後日あらためて確認させてください」と出します。
**取り繕うより、何を聞けていないかをその場で共有したほうが、後日の確認が通ります。**

### 現地でタブレットを使う場合

同じ網に出る必要があるため、**取材先のWi-Fiは使いません**（D-078）。

```

　ノートPCとタブレットの両方を、そこに繋ぐ

```

通信はすべて手元で完結するので、**データ通信量はほとんど発生しません。**

## ブロック1：導入・会社の基本（10分）

冒頭で必ず伝える：

> 「今日の90分で、サイトに載せる文章の材料を全ていただきます。**この後、御社に原稿を書いていただくことはありません。** こちらで全部書いて、確認だけお願いする形です。」

これを最初に言うと、相手の話す量が明確に増える。「後で自分が書かされる」と思っている社長は口が重い。

質問：
- 創業の経緯、現在何代目か
- 主力の事業と、売上の比率
- 従業員数、平均年齢
- 主要な取引先の業界（社名は出せなくても業界は聞く）

## ブロック2：引き合いの実態（20分）★最重要

**ここでサイト全体の設計が決まる。** 綺麗なサイトを作るのではなく、「今足りていない引き合いを取る」サイトを作るため。

### 聞くこと

- 今、問い合わせは月に何件ありますか。どこから来ていますか
- 直近で新しく始まった取引は、どうやって始まりましたか（紹介／展示会／検索／飛び込み）
- **失注するとき、理由は何が多いですか**（価格／納期／技術／信用）
- **一番利益率の高い仕事は何ですか**
- 本当はもっと受けたいのに、今あまり来ていない仕事はありますか
- 逆に、来てほしくない問い合わせはありますか（小ロット過ぎる、単価が合わない等）

### この質問群の意図

最後の2つが決定的。**「来てほしい仕事」と「来てほしくない仕事」が分かると、サイトの役割が「集客」から「選別」に変わる。**
中小製造業の社長の本音はたいてい「問い合わせ数を増やしたい」ではなく「割に合う仕事を増やしたい」。ここを言語化できると、提案の説得力が跳ね上がる。

## ブロック3：技術・設備の強み（25分）

### 製造業のWebで検索されるのは「技術の組み合わせ」

BtoB製造業の検索は、ほぼこの形：

```
[材質] × [加工法] × [条件]     例：インコネル 5軸加工 小ロット
[設備の型番]                    例：DMG MORI NTX2000 加工
[業界特有の課題]                例：薄肉 ステンレス 変形 対策
```

つまり、**カタログ的な「高品質・短納期」では一件も検索に引っかからない。** 具体の数字と固有名詞を取り切ることが、そのままSEOになる。

### 必ず数字で取るもの

| 項目 | 例 |
|---|---|
| 対応材質 | ステンレス、チタン、インコネル、樹脂……（全部列挙してもらう）|
| 対応サイズ | 最大◯◯mm × ◯◯mm、最小◯◯mm |
| 対応精度 | ±◯◯μm |
| 対応ロット | 1個〜、試作のみ可か |
| 最短納期 | ◯日 |
| 設備リスト | **メーカー名と型番まで。台数も** |
| 資格・認証 | ISO9001、ISO14001、JIS、特殊工程の資格 |
| 稼働体制 | 2交代／24時間／土日対応の可否 |

> **設備の型番は必ず取る。** 「NTX2000を持っている会社を探している」という検索が実際に存在する。多くの製造業サイトが「最新設備を多数保有」としか書いておらず、機会を丸ごと捨てている。

### 強みを言語化する質問（社長が自分では言えない部分を引き出す）

- **「他社に断られた案件で、御社が受けられたものはありますか」** ← 強みが最も鮮明に出る質問
- **「お客様から一番よく言われる褒め言葉は何ですか」** ← 顧客が感じている価値。社長の自己認識とズレていることが多く、そのズレが宝
- 「同業他社がやりたがらない仕事で、御社が得意なものは」
- 「不良率はどのくらいですか」（数字が良ければ強力な武器になる）
- 「技術的に一番難しかった仕事は何ですか」

### ★追い質問の分岐（ここで差がつく）

**上の4問だけでは、いちばん重要な強みが出てこないことがある。**

第1回モック取材では、**治具を自社で内製している**という決定的な強みが、
上の質問群では一切出てこなかった。出てきたのは、社長が「薄物は加工中に歪む」と言ったのを受けた
**技術的な追い質問**だった。

```
「薄物が歪むという話でしたが、どうやって押さえているんですか。
　ワークの固定は？　治具はどこから調達していますか？」
```

→ 社長の答え：「治具は自分で作ってます。治具屋さんに頼んだことは、あんまりないですね。
　　　　　　　　……ああ、これ、そんなに珍しいことなんですか？」

**分野知識がないと、この次の質問は出てこない。** 台本に分岐として書き残しておかないと再現できない。

| 社長の発言 | 追う質問 |
|---|---|
| 歪む・反る・暴れる | ワークの固定方法、治具の調達元、加工順序 |
| 他社が断った | 断られた理由を、相手はどう説明していたか |
| 感覚・匙加減・職人技 | その感覚を、工程・条件・順序として言い換えると何か |
| 材料が特殊 | 入手ルート、材料メーカーとの関係 |
| 測定が難しい | 測定方法、検査データの提供可否 |

> **「感覚でやっている」で止めない。** そのまま書くと「職人の勘」になり、調達担当者には響かない。
> 工程・条件・順序に翻訳して初めて、技術情報になる。

## ブロック4：実績・事例（20分）

**事例ページはBtoB製造業サイトで最も読まれ、最も問い合わせに繋がる。** 最低3本分の素材を取る。

### ★聞く前に、必ずこれを言う

```
「事例をうかがいますが、社名は一切出しません。
　『検査装置メーカー様』のように業界だけ書ければ、事例として十分に成立します。」
```

第1回モック取材では、これを言わずに聞いたため、社長は一度
**「取引先の名前は出せんのですよ」と断った**（その後、自分で「名前を出せって話じゃないですよね」と
気づいて話してくれた）。**先に明示していれば、この往復は要らなかった。**

1事例あたりに取ること：
- どんな業界の、どんな部品か（社名は出せなくても「自動車部品メーカー様」でよい）
- **相談されたときの課題**（他社で断られた／精度が出ない／コストが合わない／納期が間に合わない）
- 我々がどう解決したか（工程の工夫、治具の内製、材料の提案）
- 結果（不良率◯%改善、コスト◯%削減、納期◯日短縮）

> 秘密保持で出せない情報は「材質を伏せる」「業界を1段抽象化する」で処理できる。**「守秘義務があるので事例は出せません」で止めない。** ここで諦めると事例ページが作れず、サイトの価値が半減する。粘る。

## ブロック5：採用・その他（10分）

中小製造業の**本当の悩みは採用であることが非常に多い。**
ここを聞くと、運用契約（採用ページの継続改善・求人記事）に繋がる話が出てくる。

- 今、人は足りていますか。どの職種が足りませんか
- 直近で採用できた人は、どうやって入ってきましたか
- 若手の定着はどうですか

代表挨拶用：
- 5年後、会社をどうしていきたいですか
- 社員に一番伝えたいことは何ですか

## ブロック6：クロージング（5分）

- 写真撮影の要否と日程（工場・設備・製品・社員・社長）

## 取材後の処理（社長＝私の作業）

> **【文字起こしは信用しすぎない】**
> 第1回モック取材（音声入力で実施）では、こうした誤変換が実際に起きた。
> `実写部品→自動車部品` `産業機会→産業機械` `背番号台→旋盤5台` `画面→鋳鉄`
>
> **「画面」は文脈から復元できず、聞き直して初めて鋳鉄と判明した。**
> 原則：**文脈から明らかな誤変換は直してよい。確信が持てない箇所は絶対に推測で埋めない。**
> `{{要確認}}` を残す。**材質名・型番・数値は特に危険。**

1. 録音を文字起こし
2. **ブロック2の回答からサイトの役割を確定**（集客か、選別か、採用か）
3. ページ構成を確定 → 構成案を作成
4. 全ページの原稿を執筆
5. 写真指示書を作成（何を、どの角度で、何枚）
6. 取材から**7日以内**に構成案＋原稿第1稿を提出

## 写真指示書に必ず入れるもの

| 被写体 | 指示 |
|---|---|
| 工場外観 | 晴天・午前中。社名看板が入る角度 |
| 設備 | 稼働中。型番プレートが写るカットも別途 |
| 加工中の手元 | **最も反響が大きい写真。** 寄りで撮る |
| 製品 | 無地の背景。スケール感が分かるよう定規や手を添える |
| 社員 | 作業中の自然な表情。集合写真より個人のカット |
| 社長 | 工場内で。デスクより現場のほうが信用される |

> スマホ撮影で十分なカットと、プロ撮影が要るカットを指示書で分ける。全部プロに頼むと原価が合わない。
