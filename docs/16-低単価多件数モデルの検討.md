# 低単価・多件数モデルの検討

起案: アドバイザー（2026-09-12）
> 「製造業に絞らず、サイトのない中小・零細企業も含めたい。
> 　その場合、単価を下げて件数をこなす形で利益を出せないか」

検討: 社長 / 結論: **成立しない。ただし裏にある問題意識は正しいので、別の手で解く**

---

## 1. 結論を先に

**単価を下げて件数をこなすモデルは、週15時間の体制では成立しません。**

理由は一つです。

> **件数の上限を決めているのは制作ではなく営業で、営業工数は単価に比例して下がらないから。**

制作は年28〜60件こなせます。**営業が年9〜20件で止まります。**
単価を半分にしても、1件を取るのにかかる営業時間は半分になりません。**むしろ増えます。**

---

## 2. 試算

前提：営業に使える時間 年360時間、顧客対応＋レビュー 年360時間（`05-資金計画と稼働設計.md` 第3章）
DMは1通あたり10分（相手のサイトを見て書くルール・`08`）、フォローコールは1件10分。

| | 現計画<br>製造業特化 98万 | 低単価 30万<br>（標準前提） | 低単価 30万<br>（かなり楽観的） |
|---|---|---|---|
| DMの反応率 | 5% | 3% | 5% |
| 商談化率 | 70% | 70% | 70% |
| 受注率 | 30% | 40% | 60% |
| 1商談の所要 | 2.0h | 1.5h | 1.0h |
| **1受注に必要なDM** | 95通 | **119通** | 48通 |
| **1受注の営業工数** | 38.4h | **43.4h** | 17.5h |
| 上限（営業から） | 9.4件 | 8.3件 | 20.5件 |
| 上限（制作から） | 28.8件 | 45.0件 | 60.0件 |
| **実質の年間受注** | **9.4件** | **8.3件** | **20.5件** |
| **年間の制作売上** | **918万** | **249万** | **616万** |

### 読み取れること

**① ボトルネックは常に営業。制作ではない。**
どの列でも「制作から」の上限は「営業から」の上限の3〜7倍あります。
**制作を速く・安くしても、件数は増えません。**

**② 標準的な前提だと、低単価モデルは売上が1/4以下になる。**
単価が1/3になるのに、1受注の営業工数は **38.4h → 43.4h と むしろ増えます。**
安い商品はDMの反応率が下がるため、必要なDM通数が95通→119通に増えるからです。

**③ かなり楽観的な前提を置いても、現計画に届かない。**
受注率60%（安いので決まりやすい）、商談1時間（オンラインのみ）と甘く見積もっても616万で、現計画の918万に届きません。

**④ 現計画に並ぶには年31件必要だが、物理的に不可能。**
楽観前提の17.5h/件で31件なら、営業だけで **537時間**。
使える営業時間は年360時間、**総稼働でも年780時間**です。**営業枠の1.5倍が必要で、届きません。**

## 3. もうひとつの問題：3ヶ月かけている資産が死ぬ

業種を広げると、**準備期間に作っているものの大半が無価値になります。**

| 資産 | 製造業特化なら | 業種を広げると |
|---|---|---|
| 取材台本（`06`） | 使い回せる | **業種ごとに作り直し** |
| KOBOのフォーム | 台本の実装そのもの | **汎用の入力欄に退化** |
| 原稿生成のプロンプト | 蓄積される | 業種ごとに別物 |
| Astroテンプレート | 2件目から原価が半減 | 使い回せない |
| 業界知識 | 積み上がる | 薄く広がる |

`02-サービス設計_v0.md` で **「2件目以降の原価を下げられるかどうかで、この事業の利益率が決まる」** と書きました。
**KOBOはその実装です。業種が散ると、KOBOはただの入力フォームになります。**

そして `01-事業計画_v0.md` で製造業を選んだ理由は **「参入障壁が業界理解にあるから」** でした。
業種を広げると、その障壁はこちら側にも消えます。**サンゼンデザインの「初期0円」と同じ土俵に立つことになります**（`14` 第4章で「正面から戦わない」と決めた領域）。

---

## 4. ただし、問題意識は正しい

**母数の懸念は実在します。**

北九州商工会議所の機械金属部会は約780社。ここから
「従業員10〜100名・金属加工系・サイトが無いか古い」で絞ると、**現実的なリストは200社程度**です（`12` 第5章）。

200社 → 反応率5%で10件 → 商談7件 → 受注2件。
**年2〜3件では、計画の5〜7件に届きません。**

→ **これは対処が必要な、正当な指摘です。**

---

## 5. 対案：業種ではなく、商圏を広げる

**製造業特化は維持し、地理的な母数を増やします。**

理由は単純で、**対面が必要なのは取材90分の1回だけ**だからです。
商談も、打ち合わせも、検収もオンラインで足ります。**わざわざ業種を捨てる必要はありません。**

```
【現在】北九州市＋苅田・行橋・中間・直方・遠賀・宗像・下関　→ 約200社

【拡大後】上記 ＋ 福岡県全域（福岡市を除く製造業）＋ 山口県西部
　　　　　久留米・大牟田・飯塚・田川の工業集積、宇部・山陽小野田
　　　　　※ 具体的な母数は一次情報での確認が必要
```

**福岡市は引き続き狙いません**（制作会社が密集し価格競争になるため・`12` 第3章）。
狙うのは**福岡市以外の、製造業が集まっている市**です。そこは北九州と同じく制作会社が手薄なはずです。

移動時間：久留米まで車1.5時間、飯塚1時間、田川50分、宇部1時間。**すべて日帰り圏**です。
取材1回のために片道1.5時間なら、**98万円の案件としては十分に成立します。**

## 6. 低単価商品が成立する、唯一の条件

低単価が成立しないのは**営業工数のせい**でした。裏を返すと——

> **営業工数がほぼゼロのチャネルから来た案件になら、低単価商品は成立します。**

具体的には、**紹介・商工会議所経由・自社サイトのSEO経由**です。

```
【攻めの商品にはしない】こちらから低単価商品を売りに行かない
【受けの商品にはする】　向こうから来た小さい案件を、断らずに受ける器
```

- 対象：サイトがない零細企業、5ページ以内、取材なし
- 価格：18〜25万円
- 工数：KOBOが完成していれば、私の作業2〜3時間。アドバイザー側はほぼゼロ
- **KOBOが完成してからでないと原価が合わないため、Year 2 以降に検討**

紹介で来た小さい案件を「うちは98万からです」と断ると、**紹介の流れが止まります。**
北九州の中小製造業は横の繋がりが強い（`12` 第3章）ので、**受け皿を持っておくこと自体に意味があります。**

---

## 7. 決定

| # | 判断 |
|---|---|
| 1 | **低単価×多件数モデルは採らない。** 件数の上限は営業が決めており、単価を下げても件数は増えない |
| 2 | **業種の拡大はしない。** 取材台本・KOBO・テンプレート・業界知識という3ヶ月ぶんの資産が無価値になる |
| 3 | **母数は商圏拡大で解く。** 福岡県全域（福岡市除く）＋山口県西部へ。対面が要るのは取材90分の1回だけ |
| 4 | **低単価商品は「受けの器」としてYear 2以降に用意する。** 紹介・インバウンド経由の小案件を断らないため。こちらから売りには行かない |

### 見直す条件

- Day 150 で商談ゼロ → ターゲット業種そのものの見直し（`03` の撤退基準どおり）
- 商圏を広げても母数が足りないと判明 → 業種を**1つだけ**追加する（同時に2つは追わない）
- 体制が2名以上になった → 営業工数の制約が変わるため、低単価モデルを再計算する
