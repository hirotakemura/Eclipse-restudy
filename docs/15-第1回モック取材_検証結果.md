## 3. 【最重要】社長ひとりへの取材では、技術ページが作れない

**加工法・対応サイズ・対応精度・設備型番** の4項目すべてが「**現場に聞かないと分からない**」だった。

これは社長の落ち度ではない。経営者が公差の管理値を暗記している必要はない。
だが結果として、**BtoB製造業の検索を受け止める本体（材質×加工法×条件、設備型番）が空欄になる。**

> `06-取材台本.md` では「現場の職長・技術責任者がいると解像度が段違いに上がる」と書いていた。
> **「いるとよい」ではなく「いないと作れない」。必須条件に格上げする。**

### 対応

- 取材の同席者に **工場長／技術責任者を必須**とする
- 同席できない場合は、**別途30分の技術取材を必ずセットする**（工程に組み込む）
- **設備は銘板を写真撮影して型番を確定させる。** 口頭で聞いた型番は誤りが多く、
  間違えると検索で拾われないうえ信用も落ちる（本取材でも型番は1件しか取れず、それも要照合）

## 4. 台本の改善点

### 改善A：事例を聞く前に「社名は不要」と先に言う

罠6で社長は一度「取引先の名前は出せんのですよ」と断ったが、その後**自分で「名前を出せって話じゃないんですよね」と気づいて**話してくれた。

→ **こちらが先に明示していれば、この往復は要らなかった。**

```
【追加する前置き】
「事例をうかがいますが、社名は一切出しません。
　『検査装置メーカー様』のように業界だけ書ければ、事例として十分に成立します。」
```

### 改善B：強みの追い質問を台本に入れる（治具内製はこれでしか出ない）

罠3の治具内製は、**台本の4つの質問（他社が断った案件／褒め言葉／同業が避ける仕事／最難案件）では出てこなかった。**

出たのは、社長が「薄物は加工中に歪む」と言ったのを受けた**技術的な追い質問**だった。

```
【追加する追い質問】
「薄物が歪むという話でしたが、どうやって押さえているんですか。
　ワークの固定は？　治具はどこから調達していますか？」
```

> **これは分野知識がないと出てこない質問。**
> 薄物が歪むと聞いて「治具と加工順序に工夫があるはずだ」と分かるかどうかで、
> 取材の成果が決まる。**台本に分岐として書き残しておかないと再現できない。**

同種の分岐を他にも用意する：

| 社長の発言 | 追う質問 |
|---|---|
| 歪む・反る・暴れる | ワークの固定方法、治具の調達元、加工順序 |
| 他社が断った | 断られた理由を相手はどう説明していたか |
| 感覚・匙加減 | その感覚を、工程・条件・順序として言い換えると何か |
| 材料が特殊 | 入手ルート、材料メーカーとの関係 |

### 改善C：事前調査を取材に持ち込む

「発注の先行きに変化はありますか」と一般的に聞いても**何も出なかった。**
**「日産の九州生産移管の話、影響ありますか」と具体的に振って初めて**「今後読めない」という答えが出た。

→ 社長は、初対面の業者に取引先の事情を自分から話さない。
→ **`12-北九州商圏戦略.md` の地域情報を取材前に読み込み、こちらから振る。**
**調査は提案書のためだけでなく、取材の質を直接上げる。**

### 改善D：音声の文字起こしは信用しすぎない

今回は音声入力で実施したため、実際の取材を録音・文字起こしした状況が再現された。

```
実写部品 → 自動車部品 ／ 産業機会 → 産業機械
背番号台 → 旋盤5台　／ 画面 → 快削鋼（実際は鋳鉄だった）
```

**「画面」は文脈から復元できず、聞き直して初めて鋳鉄と判明した。**
→ 生成側の原則：**文脈から明らかな誤変換は直してよいが、確信が持てない箇所は絶対に推測で埋めない。**
`{{要確認}}` を残す。材質名・型番・数値は特に危険。**検証項目に追加する。**

## 7. 取材で得られた、最も価値のある発見

**社長が自覚していなかった強みを2つ引き出せた。**

1. **治具の内製** — 「これ、そんなに珍しいことなんですか？」
2. **設計経験による図面の意図読解** — 「参りました。自分で気づいてなかったです」

そして**この2つが、社長の言う「増やしたい仕事（半導体装置向け）」と一本の線で繋がった。**
半導体装置の部品は薄物と複雑形状の塊であり、図面が固まる前から相談できる相手を探している。

> **これが我々の商品そのもの。**
> 「顧客が言語化できない強みを引き出し、狙う市場と繋げる」ことができると実証できた。
> **原稿を書く前の段階で、既に価値が出ている。**

### 半導体キーワードへの社長の懸念と、その回答

社長から「半導体の実績が少ないのに、その言葉で人が来たら失望されないか」という指摘があった。**正当な懸念。**

回答：**「半導体」を看板にせず、半導体装置メーカーが困って検索する言葉で待ち構える。**

| 書かない | 書く |
|---|---|
| 半導体装置部品の実績多数 | 装置部品の薄物・複雑形状加工 |
| 半導体業界に対応 | 図面が確定する前からの試作対応 |

嘘がなく、来た人が失望しない。実績が積み上がった時点で書き足せる。
**この判断基準は、事実検証の安全装置（D-013）と同じ思想。** 他案件でも同様に扱う。
