# 第8段階 — 装飾（decoration）とモーションの設計・記録

`bc01a94` `0f1e49d` `5a9bda5` ／ D-361〜363

第7段階（余白・タイポグラフィ）の次として、**装飾と仕上げ**を扱った段。

## ① 棚卸し — 装飾システムは、すでに4層あった

| 層 | 語彙 | 実体 |
|---|---|---|
| 面 `surface` | plain / soft / accent / grid / rule / paper / dark（7） | CSS |
| 地紋 `motif` | none / dimension / grid / process / section / grain（6） | CSS。材料があるときだけ付く |
| 描く `graphic` | 新たに描くのは **light / geometry の2つだけ** | CSS。`MOTIF_AS`／`PATTERNED` が二重掛けを禁じる |
| 素材 `library` | **texture のみ** | 静的SVG。`assertLibrary` が主題・面・パスを強制 |

主題は「実写でしか撮れない6種（workpiece / facility / exterior / person / workplace / product）」と
「描ける5種（texture / grid / dimension / geometry / light）」に分離済みで、
**前者は evidence、後者は atmosphere** という線がコードに入っている。

### 15方向 → 5群で足りる

| 群 | 方向 | 許可する装飾 | AI画像 |
|---|---|---|---|
| 装飾を持たない | standard, gstandard | 面と罫のみ | 不要 |
| 図面系 | technical, engineering, modern | grid / dimension / geometry | **禁止**（実在の図面と誤認される） |
| 素材・手仕事系 | craft, classic, editorial, luxury | texture | 抽象テクスチャの原画としてのみ |
| 設備・量産系 | industrial, product | dark面＋light | **禁止**（誤認リスク最大） |
| 人・サービス系 | seikatsu, human, shop, dynamic | geometry / light。人・店・商品は**実写依頼** | **禁止** |

**結論：AI画像は要らない。** atmosphere の主題は5つとも CSS/SVG で描けて、
evidence の主題はそもそも生成禁止（＝写真依頼が正）。
唯一あり得るのは「ライブラリに置く抽象テクスチャの原画を1回作る」場面だけで、
その場合も**生成をビルド経路に入れない**（決定性のため）。

## ② 素材を2枚から4枚にした（D-361）

実測で、**紙の目1枚を4つの型で共有**していた（product / classic / editorial / luxury）。
色も書体も余白も型ごとに変えているのに、**地の目だけが全部同じ**になる。

| 素材 | 型 | 実測の出番 |
|---|---|---|
| 紙 `paper-grain` | editorial | 検証データでは出番なし（`none` のまま成立＝原則どおり） |
| 布 `linen-grain` | craft | 対応範囲・会社概要 |
| 木 `wood-grain` | classic | 会社概要 |
| 金属 `metal-hairline` | luxury / product | トップ／対応範囲・会社概要 |

`subject` は `texture` のまま。面も地紋も graphic も増やしていない。

**2枚とも画面に出して目で確かめた。**
最初の金属は他の3枚と同じ `feTurbulence` で作ったが、**画面ではほぼ何も見えなかった**
（縦の周波数を上げるほど線が1pxを割って平らな灰色に均される）。**見えない装飾は、
足していないのと同じである**（D-357と同じ形）。規則的な矩形の繰り返しに描き直した。
木も最初は布と同じ横向きで、**並べると「粗い布」にしか見えなかった**ので縦向きにした。

## ④⑤ モーションの仕上げ（D-363）

動きは既に実装済みだった（`motion` 軸と3つの `@keyframes`）。抜けていたのは**仕上げ**のほうで、
`:focus-visible` が問い合わせ欄にしかなく、hover の遷移も3箇所だけだった。

### 採用したもの

1. **時間の語彙化** — `--m-fast .18s` / `--m-rise .5s` / `--m-peak .7s`。
   CSSに散っていた同じ数字を寄せただけで、**新しい数値は作っていない**（D-197）。
2. **操作の応答** — ボタン・ナビ・本文リンク・電話番号に 0.18s。**色と下線だけ・移動なし。**
   本文リンクの色を変えないのは、**白抜きの地で白い文字が濃い色に落ちて読めなくなる**ため（D-358）。
3. **焦点** — `:focus-visible` を全操作要素へ。**`prefers-reduced-motion` の外**に置き、常に出す。
   色地・暗い地・CTAでは輪郭も白に倒す。
4. **スマホのメニュー** — 透明度だけ。**高さは動かさない**（開くたびに読み位置が飛ぶ）。

### 採用しなかったもの

ページが開いたときのフェード／ページ遷移／視差／ループ／数え上げ（D-240で取り下げ済み）／
指を乗せたときの拡大・影／sticky の追従／20pxを超える移動／文字そのものの移動。
**すべて試験で見張っている。**
