# 素材（Asset）の見え方 — 人が見て判断するもの

作成 2026/9/15　／　`npm run qa:assets` が作っています

**機械が確かめたことは、ここには書きません。**（画面に出ています）
ここにあるのは、**人が画面を見ないと決められないこと**だけです。

> 数にしないでください。**「装飾が何本」「写真が何枚」は品質ではありません。**
> `none`（素材を置かない）は、決まらなかったのではなく**要らないと決めた**状態です。

---

## この画面の撮り直し方

```
cd tool && npm run qa:assets
```

PNGは**Gitに入れていません**（`.gitignore`・D-328）。上を実行すると同じ場所に出ます。
画面は手元で見るもので、履歴に積むものではない、という判断です。

## 見るところ

### 1. 写真0枚でも未完成に見えないか

- A 写真0枚 の3枚。**穴が空いて見えないか。** 装飾が無い型（落ち着き・信頼）も同じ目で見る
- [ ] 見た　／　気づいたこと：

### 2. 写真がある場合、意味のある使われ方になっているか

- B と C。**その写真でなければいけない場所に出ているか**（事例の写真が事例のページに、など）
- [ ] 見た　／　気づいたこと：

### 3. 視線の流れがあるか

- 各型のトップ。上から下へ、止まる場所と流す場所があるか
- [ ] 見た　／　気づいたこと：

### 4. ページに適切な Visual Peak があるか

- 各型のトップ。**どこが山か、目で分かるか**
- [ ] 見た　／　気づいたこと：

### 5. 会社ごとの個性が感じられるか

- 6つの型を並べて見る。**同じ会社データで型だけを変えている**ので、差は型の差である
- [ ] 見た　／　気づいたこと：

### 6. 装飾過多になっていないか

- モダン・力強い。**装飾が本文より目立っていないか**
- [ ] 見た　／　気づいたこと：

### 7. 写真が単なる穴埋めになっていないか

- C 十分。**枚数が増えただけになっていないか**
