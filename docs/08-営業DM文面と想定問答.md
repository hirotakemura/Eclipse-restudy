# 営業DM文面・フォローコール台本・想定問答

作成: 2026-09-12 / 対象: BtoB中小製造業の社長宛

---

## 1. なぜメールではなく封書か

- 中小製造業の社長は**メールをほぼ見ない**。info@ 宛は総務で止まる
- 一方、**社長宛の封書は本人に届き、本人が開ける**
- 営業メールが飽和している今、紙のほうが相対的に競争が少ない

**送付先は必ず社名＋代表者名。**「ご担当者様」は捨てられる。

| 送り方 | 単価 | 開封率 |
|---|---|---|
| 普通郵便（長形3号） | 約200円 | 低 |
| **レターパックライト** | **約480円** | **高。推奨** |

50通で約2.4万円。Phase 2 の営業費（月3万）に収まる。

## 2. DM文面（A4・1枚）

**1枚を厳守。2枚目は読まれない。**

```
{{会社名}}
代表取締役 {{代表者名}} 様

突然のお手紙を失礼いたします。
{{屋号}}の{{氏名}}と申します。

{{地域}}の製造業に特化して、Webサイトの制作を行っております。

先日、「{{キーワード}}」で検索をしておりましたところ、
御社のお名前を拝見し、サイトを拝見いたしました。

{{具体的な所感を1〜2文。例：}}
5軸加工とワイヤーカットの両方を自社で完結できる体制は、
この地域では数社しかないのではないかと拝察いたしました。

一方で、ひとつ気になった点がございます。
御社のサイトには、対応可能な材質・サイズ・精度、
そして保有設備の型番が記載されておりません。

発注先を探している調達担当者が最も知りたい情報が、
ちょうど載っていない状態になっております。
「{{キーワード}}」の検索では、現在 御社は50位以下でした。

──────────────────────────────────

もしご関心がありましたら、
御社サイトの診断書（A4・3枚程度）を無料でお送りいたします。

　・検索順位の実測と、上位3社との比較
　・調達担当者の視点で不足している情報の一覧
　・改善の優先順位

営業はいたしません。ご不要であれば、その旨ご返信いただくだけで結構です。

同封の返信はがき、またはお電話・メールにてお知らせください。

　{{屋号}}　{{氏名}}
　TEL: {{電話番号}}　Mail: {{メールアドレス}}
　{{URL}}
```

### 文面設計の意図

| 要素 | 意図 |
|---|---|
| 冒頭で「検索して見つけた」と書く | 無差別DMではないと示す |
| **相手のサイトを見た証拠を具体的に書く** | ここが全て。ここが一般論だと即ゴミ箱 |
| 褒めてから、1点だけ問題を指摘 | 全否定すると読まれない。1点に絞ると刺さる |
| **検索順位という客観的事実**を出す | 主観ではなく事実なので反論されない |
| CTAを「無料診断書」に置く | 商談のハードルが高い。情報提供なら受け取りやすい |
| **「営業はいたしません」と明記** | 最大の心理的障壁を先に取り除く |
| 返信はがきを同封 | 電話もメールもしたくない層を拾える |

> **1通ごとに相手のサイトを見て、具体的な所感を書く。** テンプレのまま50通送っても反応はゼロ。1通あたり10分かけて、**週10通のペースで送るほうが、一括50通より結果が出る。**

## 3. フォローコール台本（発送から5営業日後）

```
「お世話になります。{{屋号}}の{{氏名}}と申します。
　先日、{{代表者名}}社長宛にお手紙をお送りしたのですが、
　お手元に届いておりますでしょうか。」

（取り次いでもらえた場合）

「お忙しいところ恐れ入ります。
　{{地域}}で製造業専門にWebサイトを作っております{{氏名}}と申します。
　先日お手紙でお送りした、サイトの無料診断書の件でお電話いたしました。

　御社のサイトを拝見して、{{具体的な指摘}}という点が気になりまして。
　診断書をお送りするだけでしたら5分もかかりませんので、
　もしよろしければ作らせていただければと思うのですが、いかがでしょうか。」
```

**この電話のゴールは「診断書を送る許可をもらうこと」であって、アポを取ることではない。**
ハードルを下げる。診断書を送った後の反応で、見込みを判断する。

## 4. 想定問答

### 「今は間に合っています」

> 「承知しました。実は、Webから引き合いが来ていない会社さんのほとんどが同じことをおっしゃいます。
> ただ、今来ている仕事が来年も同じように来るかというと、そこは分からないところがありまして。
> 診断書だけお送りしておきますので、お手すきのときにご覧ください。それで終わりにしていただいて結構です。」

→ **食い下がらない。** 診断書を送る許可だけ取って引く。半年後にリストへ戻す。

### 「予算がない」

> 「ありがとうございます。実は持続化補助金という制度がありまして、Webサイトの制作費が3分の2まで補助されます。
> 98万円のサイトでしたら、実質のご負担は33万円ほどです。申請書類の作成もこちらでお手伝いしています。
> 補助金の話だけでもご説明できればと思うのですが。」

→ **「予算がない」は多くの場合「その金額の価値が分からない」の言い換え。** 補助金は金額のハードルを実際に下げつつ、話を続ける口実になる。

### 「他社と相見積もりを取りたい」

> 「もちろんです。比較いただいたほうが良いと思います。
> ひとつだけ、比較の際に確認いただきたい点がありまして。**原稿をどちらが書くのか**をご確認ください。
> 多くの制作会社さんは御社に書いていただく前提です。そこで止まって半年かかるケースが非常に多いので。」

→ **相見積もり自体は止められない。比較の軸を我々の土俵に変える。** これを言われた競合は、原稿の話を持ち出された時点で不利になる。

### 「値引きしてほしい」

> 「金額を下げるのではなく、内容を調整させてください。
> 10ページを6ページに絞る形でしたら{{金額}}円でご提案できます。
> ただ、加工事例のページだけは残させてください。ここが一番問い合わせに繋がる部分ですので、削ると成果が出なくなってしまいます。」

→ **絶対に金額だけを下げない。**

### 「サイトを作っても問い合わせなんて来ない」

> 「おっしゃるとおりで、作っただけでは来ません。
> 前のサイトで来なかった理由は、たいてい**載っている情報が足りない**ことにあります。
> 調達の方が探しているのは会社の理念ではなく、『この材質を、この精度で、このロットで作れるか』という情報です。
> そこを載せると反応が変わります。」

→ **相手の経験を否定しない。** 否定した瞬間に終わる。「おっしゃるとおり」から入って、原因を specifics に変える。

### 「実績を見せてください」（創業期の最大の弱点）

正直に、かつ強く答える。ごまかすと必ず見抜かれる。

> 「独立したばかりですので、社名を出せる実績はまだ多くありません。そこは正直に申し上げます。
> ですので、**御社には最初のお客様として、相応の条件でお受けしたい**と考えています。
> その代わり、実績として掲載させていただくことをお願いするかもしれません。
>
> 実力の判断材料としては、今日お送りした診断書をご覧ください。
> 他社さんの提案書と比べていただければ、調べている量は違うと思います。」

→ **実績の不足は、診断書の質でしか埋められない。** だから初期はDM1通・提案1件にかける時間を惜しまない。

### 「知り合いの業者に頼んでいます」

> 「そうでしたか。長くお付き合いのある会社さんがいらっしゃるのは良いことだと思います。
> 差し支えなければ、更新はスムーズに進んでいますか。
> 『頼みづらくて放置している』というお話をよくうかがうもので。」

→ **既存業者を悪く言わない。** 不満があれば相手から出てくる。出てこなければ引く。

## 5. 追わないと決めておくこと

週15時間しかない。**見込みの薄い相手を追う時間が、最大の損失。**

| 状況 | 判断 |
|---|---|
| 「今すぐではない」 | 追わない。リストに戻して6ヶ月後に再接触 |
| 3回連絡して反応なし | 打ち切り |
| 相見積もり3社以上のコンペ | **辞退する。** 勝率3割の案件に12時間は使えない |
| 値引き前提で話が始まる | 辞退する |
| 担当者止まりで社長に会えない | 保留。中小製造業は社長決裁 |

**断る基準を先に決めておく。** 案件が少ない時期ほど、悪い案件を飲みたくなる。そこで飲むと、その1件に時間を取られて良い案件を取りにいけなくなる。
