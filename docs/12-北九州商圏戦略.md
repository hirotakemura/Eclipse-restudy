作成: 2026-09-12 / 商圏確定: 北九州市およびその近辺
※ 本書の事実関係は2026年9月時点の調査に基づく。出典は末尾。

## 1. 結論：製造業特化をやるなら、日本で最も条件の良い地域のひとつ

`01-事業計画_v0.md` で「BtoB中小製造業に特化する」と決めたが、**北九州はその戦略と噛み合いすぎている。**

| 条件 | 北九州の状況 |
|---|---|
| 製造業の集積 | 官営八幡製鐵所（1901年）以来115年以上の産業拠点。**製造品出荷額は苅田町を含めると全国第7位** |
| 産業構成 | 鉄鋼・化学などの素材産業 ＋ 金属・機械の加工組立産業。**製造業の構成比は政令市平均より顕著に高い** |
| 完成車メーカー | 日産自動車九州（苅田町）、トヨタ自動車九州、ダイハツ九州。**半径50km圏に主要サプライヤー約50社、九州・山口の自動車関連産業は990社以上** |
| Web制作会社の分布 | 福岡市（天神・博多）に集中。**北九州は相対的に手薄**（要検証・第7章） |

さらに事業所数・従業者数は減少傾向にある一方、製造品出荷額は維持されている。
これは **「残っている会社は強いが、経営者は高齢化し、事業承継が進んでいる」** ことを意味する。

`01` で「二代目・三代目が入った会社」をターゲット条件に挙げたが、**北九州はその母集団が全国有数に厚い。**

## 2. 2026年の追い風（これは異常に良いタイミング）

| 時期 | 出来事 |
|---|---|
| 2026年3月 | **北九州響灘洋上ウインドファーム 営業運転開始。** 総出力22万kW、事業費1,700億円。国内最大級 |
| 2026年6月 | 九州経済産業局・関係自治体・九経連等により**九州の洋上風力クラスターが結成** |
| 2026年7月 | 政府の**「戦略産業クラスター計画」第1弾**に、**九州の半導体サプライチェーン**と**九州の洋上風力**が選定 |
| 進行中 | 北九州市が**フィジカルAI関連人材を5年で1万人育成、3,000億円の設備投資誘致**を計画 |
| 進行中 | **日産の九州生産移管**に対し、北九州市が支援チームを設置し用地・補助制度を案内 |

### これが我々にとって何を意味するか

**設備投資が動く地域では、その周辺の中小製造業に「新しい取引先を探す動き」が生まれる。**

- 洋上風力 → 鋼構造物、大型溶接、メンテナンス、精密部品
- 半導体 → 装置部品、精密加工、表面処理、クリーン対応
- 日産の生産移管 → ティア2・ティア3への発注構造の組み替え

**新しい発注元に見つけてもらう必要が生じたとき、中小製造業が最初に困るのが「うちの技術を説明できるサイトがない」こと。** これがそのまま我々の商談の入口になる。

DM文面（`08`）の書き出しに、この文脈を使える：

> 「響灘の洋上風力や、九州の半導体関連で新しい引き合いが動いております。
> そうした新しい発注元は、まず御社のサイトを見て技術を確認します。」

## 4. ターゲットの具体化

### 優先する業種（自動車・半導体・環境エネルギーのサプライチェーン）

| 業種 | 優先度 |
|---|---|
| 金属加工（切削・旋盤・マシニング） | ◎ |
| 板金・製缶・溶接 | ◎ |
| 機械部品・治具・装置設計 | ◎ |
| 表面処理（メッキ・熱処理・塗装） | ○ 技術の説明が難しく、書ける制作者が特に少ない |
| 樹脂成形・ゴム | ○ |
| 電気制御盤・配線 | ○ |
| 鋳造・鍛造 | ○ |

### 企業規模

**従業員10〜100名。** 理由：
- 10名未満：Web投資の予算がない
- 100名超：既に制作会社と取引があるか、情報システム部門が判断する（意思決定が遠い）

### 優先順位をつける条件（この順に当たる）

1. **サイトが存在しない、または明らかに5年以上更新されていない**
2. **二代目・三代目が経営に入っている**（会社概要の役員構成、代表挨拶の文面から推測できる）
3. 自動車・半導体・環境エネルギーいずれかのサプライチェーンにいる
4. 直近で設備投資している（新しい設備の記載、求人票の内容から分かる）
5. 採用に困っている（求人を継続的に出している）

## 5. 営業リストの作り方 ★大きな発見

### 「ものづくり北九州企業データベース」

→ https://net.kitakyushucci.or.jp/mono-db/

**調査で判明したこと（2026年9月時点）：**

| | |
|---|---|
| 運営 | **北九州商工会議所の機械金属部会** |
| 母集団 | **部会に約780社**（製造、鉄鋼、金属成形材料、自動車部品、一般機械） |
| 検索条件 | **業種／保有設備／工業団地の所在地／大学・公設試** |
| 目的 | 会員企業が互いの事業を知り、**地元取引・採用の橋渡しをすること** |

**これは営業リストとして理想的です。理由は3つ。**

1. **「保有設備」で検索できる。** 我々のターゲット条件（切削・板金・製缶・表面処理）でそのまま絞り込める。設備で企業を引ける名簿は珍しい
2. **母集団780社。** 従業員10〜100名で絞っても、200社のリストは十分に作れる
3. **掲載企業は「取引先を探している」状態にある。** DBの目的が地元取引の橋渡しなので、掲載している時点で新規取引に前向き。しかも自社の設備や技術を**見せる気がある**会社＝Web投資への理解がある可能性が高い

### 【アドバイザーへの確認事項】スタート時に見ていただきたいこと

上記で大枠は判明したので、**残る確認は4点だけ**です。

| # | 確認すること | なぜ必要か |
|---|---|---|
| 1 | **各社の掲載項目に自社サイトURLがあるか** | **最重要。** URLが無い／古い会社を抽出すれば、それが最優先のDM送付先になる |
| 2 | 従業員数が載っているか | ターゲット条件（10〜100名）で絞るため |
| 3 | 一覧をCSV等で出力できるか | 手作業で200社を転記するのは時間が惜しい |
| 4 | 閲覧・掲載は会員限定か | 会員限定なら、入会が前提条件になる |

### ターゲットリストの抽出条件（先に確定しておく）

DBの検索軸が分かったので、**抽出条件は今のうちに確定しておきます。**
スタート時は、この条件どおりに絞るだけで済むようにしておく。

```
【必須条件】
　所在地　　北九州市7区／苅田町／行橋市／京都郡／中間市／直方市／遠賀郡／宗像市
　業種　　　金属加工・機械部品・板金・製缶・溶接・表面処理・樹脂成形・電気制御盤
　従業員　　10〜100名

【優先順位（この順に当たる）】
　A　サイトが無い、または5年以上更新されていない　　← 最優先
　B　二代目・三代目が経営に入っている
　C　自動車／半導体／環境エネルギーのサプライチェーン
　D　直近で設備投資している（新しい設備の記載、求人内容から判断）
　E　採用に困っている（求人を継続的に出している）

【除外】
　・従業員10名未満（Web投資の予算がない）
　・従業員100名超（情報システム部門の判断になり、意思決定が遠い）
　・既に制作会社が入っていて、サイトが新しく作り込まれている
```

### 補助的なリストソース

- 北九州市の企業立地ガイド（産業経済局 企業誘致課）
- 北九州市産業集積実施計画（集積区域が公開されている）
- 各種工業団地の入居企業一覧
- 求人サイト（設備投資・採用に動いている会社が分かる）

## 6. 支援機関・営業チャネル

### 北九州テクノセンタービル（戸畑区）★まずここに行く

北九州市の **中小企業振興課** と、公益財団法人北九州産業学術推進機構（FAIS）の **中小企業支援センター** が**同じ建物の1階に同居**し、連携してワンストップで支援を提供している。

→ **中小企業支援の相談・補助金・企業紹介の窓口が物理的に1箇所にまとまっている。** Phase 1 でここに挨拶に行く。

| 機関 | 使いどころ |
|---|---|
| **北九州商工会議所** | **入会する。** 持続化補助金の窓口であり、ものづくり企業DBの運営元でもある。会員であること自体が信用になる |
| **FAIS 中小企業支援センター**（ktc.ksrp.or.jp） | 補助金情報、専門家派遣、企業とのマッチング |
| 北九州市 中小企業振興課 | 市独自の補助制度 |
| 福岡県 DX推進センター | 無料の伴走支援。県の補助金と組み合わせられる |
| 九州経済産業局 | 洋上風力・半導体クラスターの文脈 |

### 使える可能性のある補助金（**必ず最新の公募要領を確認すること**）

| 制度 | 状況 |
|---|---|
| 小規模事業者持続化補助金 | **ウェブサイト関連費は補助金交付申請額の1/4・上限50万円。単独申請不可**（`07` の訂正を参照） |
| **北九州市 DX推進補助金（デジタル化枠）** | 市独自制度。2026年度の実施状況を要確認 |
| 福岡県 生産性向上・賃上げ緊急支援補助金 | 最大2,250万円規模との情報あり。要件・対象経費を要確認 |
| ものづくり補助金 | 設備投資が主。Web単体は対象になりにくい |

> **地元の制度に詳しいことが、福岡市の競合に対する最大の差別化になる。**
> 福岡市の制作会社は北九州市独自の制度まで把握していない。ここは調べれば勝てる領域。
> **ただし制度は毎年変わる。提案書に金額を書く前に、必ず当該公募回の要領を確認する。**

## 7. 競合状況（仮説と、検証すべきこと）

**仮説：Web制作会社は福岡市に集中しており、北九州市内は手薄。**

根拠（いずれも状況証拠であり、検証が必要）：
- 福岡市は九州の広告・IT産業の中心地
- 福岡市の制作会社は市内の案件で足りており、北九州まで営業に来る動機が薄い
- JR快速で約50分。物理的には近いが、営業圏としては分断されやすい距離

**【検証タスク・社長担当】**
- 「ホームページ制作 北九州」「ホームページ制作 小倉」での上位10社の実態調査
- そのうち北九州市内に拠点がある会社は何社か
- **製造業に特化している会社が存在するか**（ここが本当の競合）

→ Phase 1 で実施する。**もし製造業特化の制作会社が既に北九州にいるなら、戦略の見直しが必要。**

## 8. 屋号の結論（`09-屋号候補.md` の更新）

### 結論：屋号に地域名は入れない。タグラインで地域と業種を言う。

```
　屋号　　　　ものづくりウェブ
　タグライン　北九州の製造業専門のホームページ制作
```

**地域名を入れない理由：**

1. **商圏が自然に広がる。** 苅田・行橋・中間・直方・宗像、そして下関。「北九州ものづくりウェブ」だと、苅田や下関の会社に「うちは北九州じゃない」と思われる
2. 法人化のとき、社名を変えずに済む
3. 「地元感」はタグライン・名刺・サイトで十分に出せる

**一方でSEOでは地域名を全面に出す。** サイトのタイトルタグと見出しで「北九州」「小倉」を明示する：

```
ホームページ制作 北九州｜製造業専門｜ものづくりウェブ
```

### 狙うキーワード

| 我々自身のSEO | 顧客サイトのSEO（提案の根拠になる） |
|---|---|
| ホームページ制作 北九州 | {{加工法}} 北九州 |
| ホームページ制作 小倉 | {{材質}} 加工 福岡 |
| 製造業 ホームページ制作 福岡 | 試作 九州 |
| 工場 ホームページ 制作 | {{設備型番}} 加工 |
