# 調査ノート

デザインや実務の判断の裏を取るための調査を、ここに貯めます。

**この事業では、裏の取れていない数字を根拠にして判断を誤った反省があります**（D-116）。
調査は「何が確かで、何が推測か」を分けて書くこと。書けないなら「未確認」と書くこと。

| ファイル | 状態 |
|---|---|
| `デザイン調査_製造業サイトの型.md` | **完了。ただし直接観察はゼロ**（後述） |
| 日本語の可読性（文字サイズ・行間・コントラスト比） | **未完了。** 調査の途中で止まったため、成果物なし。**再実施が必要** |

## この環境の制約（重要）

**社内のネットワークから、外部サイトのHTML/CSSを取得できません。**
`WebFetch` も `curl` も、試したドメインはすべて遮断されました。通るのは検索の要約だけです。

そのため、製造業サイトの調査は**「検索結果の要約から読み取った傾向」**であって、
**実際のサイトを見て確かめた事実ではありません。** 文書の冒頭にもその旨が書かれています。

→ **Day 90 までに、制限のない環境（普段お使いのMacのブラウザ）で実サイトを見て確かめること。**
　 そのときに埋めるべき穴の一覧は、調査文書の末尾にあります。
