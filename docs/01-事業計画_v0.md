## 1. 前提認識：この市場で「普通のWeb制作会社」をやると死ぬ

2026年時点の現実を直視する。

- **下限価格が崩壊している。** STUDIO / Wix / ペライチ + 生成AIで、「そこそこ見られるサイト」は事業者自身が数万円で作れる。「きれいなサイトを作ります」は商品として成立しない。
- **単発制作モデルは営業コストで死ぬ。** 1件80万の制作を受注するのに商談5件必要なら、営業工数が利益を食い潰す。作り終わった瞬間に売上ゼロに戻るモデルは、1人〜数人規模では回らない。
- **一方で、中小企業のWeb案件は依然として供給不足。** 特に「業界を理解して、原稿まで書いてくれる制作者」が絶望的に足りない。

→ 結論：**制作会社ではなく「特定業種のWeb集客の外注先」として設計する。** 制作は入口の商品であって、本体は継続的な運用収益。

## 2. ポジショニング（社長の提案）

### ターゲット：BtoB中小製造業（従業員10〜100名）

| 候補業種 | 評価 |
|---|---|
| 歯科・整骨院・美容室 | ✗ レッドオーシャン。専門制作会社が数十社、価格競争が激しい |
| 飲食・小売 | ✗ 客単価が低く、Web投資の余力が小さい。食べログ/Instagramで代替される |
| 士業（税理士・社労士） | △ 単価は取れるが競合の制作会社が多い。第2候補 |
| 工務店・リフォーム | △ 単価は高いが、ポータル（SUUMO等）に予算を吸われている |
| **BtoB中小製造業** | **◎ 本命** |

**BtoB中小製造業を選ぶ理由：**

1. **参入障壁が「業界理解」にある。** 切削、板金、樹脂成形、装置設計……技術内容を理解して書ける制作者が少ない。デザイン力での勝負を回避できる。
2. **1件の引き合いの価値が異常に高い。** 新規取引が始まれば年間数百万〜数千万の継続取引になりうる。「月2件の問い合わせ増」の価値が明確で、月額運用費を正当化しやすい。
3. **競合が弱い。** 多くが「地元の印刷会社が作った10年前のサイト」。まともなサイトにするだけで差がつく。
4. **相見積もりになりにくい。** 一度信頼されると長い。解約率が低い＝ストック収益が安定。

**リスク：** 意思決定が遅い（社長決裁だが動き出しに数ヶ月）、DX意識の低い会社に当たると教育コストが高い。→ 「補助金が動いている会社」「二代目・三代目が入った会社」に絞ることで緩和する。

### 我々の武器：原稿を客に書かせないこと

中小企業のWeb制作が失敗・停滞する最大の理由は、**原稿が上がってこないこと**。
これは業界共通の課題で、ほぼ全ての制作会社が「原稿をお待ちしています」で3ヶ月止まる。

我々の商品設計：
> **取材90分1回で完結。原稿・構成・写真の指示書まで全てこちらが作る。納品まで4週間。**

生成AIを制作プロセスに組み込むことで、これを原価的に成立させる。これが技術的な優位であり、同時に**顧客にとって一番刺さる訴求**（「楽で、早い」）になる。

## 3. 収益モデル

```
              初期制作（フロー）        月額運用（ストック）
              80〜150万 / 件      →    5〜15万 / 月
              ────────────────         ────────────────
              受注のための商品          事業の本体
              利益率は高くない          ここで生きる
```

**KGI：年間の粗利**（2026-09-12 改訂）

月額の保守料をいただかない方針に変更したため、KGIをMRRから年間粗利に変えた（D-054）。
制作売上は変動するが、**粗利率が高いので、少ない件数でも固定費を大きく上回る。**

| | 売上 | 友人への成果報酬 | 原価計 | **粗利** |
|---|---|---|---|---|
| 製造業（友人が開拓・30%） | 980,000円 | 294,000円 | 345,500円 | **634,500円（65%）** |
| 汎用（紹介経由・10%） | 198,000円 | 19,800円 | 21,300円 | **176,700円（89%）** |

※ 原価には Claude API の原稿生成費 約1,500円と、製造業案件の写真外注 50,000円を含む。

**先行指標：継続的な接点を持つ顧客数**
月次レポートを送り続けている先の数。原価がほぼゼロで、**更新依頼・追加案件・紹介の出どころになる**（D-045）。

> **固定費は月41,000円。汎用案件が月1件（粗利176,700円）あれば、それだけで4ヶ月分の固定費が出る。**
> 「潰れない」ラインは、以前考えていたより遥かに手前にある。

### 3年の形

> **【2026-09-12 改訂】件数と年商の計画値は置かない（D-050）。**
>
> 営業を友人が担当することになり、**件数の上限を決めるのは友人の営業量**になった。これは未知の数字。
> 先に計画値を置くと、**それに合わせて品質を落とす判断が入り込む。** 実績が出てから測る。
>
> 分かっているのは単位あたりの経済性だけなので、それだけを書いておく。

| | 1件あたりの粗利 | 固定費（月41,000円）の何ヶ月分か |
|---|---|---|
| 製造業（友人が開拓・30%） | 634,500円 | **約15ヶ月分** |
| 汎用（紹介経由・10%） | 176,700円 | **約4ヶ月分** |

**体制：** アドバイザー（事業主・取材同席・保守）／友人（営業・取材主担当・外注）／社長（制作・戦略）

※ 週10〜20時間（副業）の稼働前提で引き直した数字。根拠は `05-資金計画と稼働設計.md` 第3章。

## 6. 補助金

> **【訂正 2026-09-12】** 初版で「上限50〜200万」と書いたが、**ウェブサイト関連費には別途「補助金交付申請額の1/4・上限50万円」という制限があり、単独申請もできない。**
> サイト制作費の大半を補助金で賄うことはできない。詳細と正しい伝え方は `07-提案書テンプレート.md` を参照。

補助金は**それ自体を売りにするのではなく、「申請を手伝える会社」であることを信用の材料にする。**
制度は毎年変わり、地域独自の制度もある（北九州市DX推進補助金、福岡県の生産性向上支援など）。
**地元の制度に詳しいことは、福岡市の競合に対する明確な差別化になる**（`12-北九州商圏戦略.md`）。
