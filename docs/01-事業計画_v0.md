# 事業計画 v0（社長ドラフト）

作成: 2026-09-12 / 起案: 社長 / 状態: **アドバイザー承認待ち**

---

## 1. 前提認識：この市場で「普通のWeb制作会社」をやると死ぬ

2026年時点の現実を直視する。

- **下限価格が崩壊している。** STUDIO / Wix / ペライチ + 生成AIで、「そこそこ見られるサイト」は事業者自身が数万円で作れる。「きれいなサイトを作ります」は商品として成立しない。
- **単発制作モデルは営業コストで死ぬ。** 1件80万の制作を受注するのに商談5件必要なら、営業工数が利益を食い潰す。作り終わった瞬間に売上ゼロに戻るモデルは、1人〜数人規模では回らない。
- **一方で、中小企業のWeb案件は依然として供給不足。** 特に「業界を理解して、原稿まで書いてくれる制作者」が絶望的に足りない。

→ 結論：**制作会社ではなく「特定業種のWeb集客の外注先」として設計する。** 制作は入口の商品であって、本体は継続的な運用収益。

## 2. ポジショニング（社長の提案）

### ターゲット：BtoB中小製造業（従業員10〜100名）

| 候補業種 | 評価 |
|---|---|
| 歯科・整骨院・美容室 | ✗ レッドオーシャン。専門制作会社が数十社、価格競争が激しい |
| 飲食・小売 | ✗ 客単価が低く、Web投資の余力が小さい。食べログ/Instagramで代替される |
| 士業（税理士・社労士） | △ 単価は取れるが競合の制作会社が多い。第2候補 |
| 工務店・リフォーム | △ 単価は高いが、ポータル（SUUMO等）に予算を吸われている |
| **BtoB中小製造業** | **◎ 本命** |

**BtoB中小製造業を選ぶ理由：**

1. **参入障壁が「業界理解」にある。** 切削、板金、樹脂成形、装置設計……技術内容を理解して書ける制作者が少ない。デザイン力での勝負を回避できる。
2. **1件の引き合いの価値が異常に高い。** 新規取引が始まれば年間数百万〜数千万の継続取引になりうる。「月2件の問い合わせ増」の価値が明確で、月額運用費を正当化しやすい。
3. **競合が弱い。** 多くが「地元の印刷会社が作った10年前のサイト」。まともなサイトにするだけで差がつく。
4. **相見積もりになりにくい。** 一度信頼されると長い。解約率が低い＝ストック収益が安定。

**リスク：** 意思決定が遅い（社長決裁だが動き出しに数ヶ月）、DX意識の低い会社に当たると教育コストが高い。→ 「補助金が動いている会社」「二代目・三代目が入った会社」に絞ることで緩和する。

### 我々の武器：原稿を客に書かせないこと

中小企業のWeb制作が失敗・停滞する最大の理由は、**原稿が上がってこないこと**。
これは業界共通の課題で、ほぼ全ての制作会社が「原稿をお待ちしています」で3ヶ月止まる。

我々の商品設計：
> **取材90分1回で完結。原稿・構成・写真の指示書まで全てこちらが作る。納品まで4週間。**

生成AIを制作プロセスに組み込むことで、これを原価的に成立させる。これが技術的な優位であり、同時に**顧客にとって一番刺さる訴求**（「楽で、早い」）になる。

## 3. 収益モデル

```
              初期制作（フロー）        月額運用（ストック）
              80〜150万 / 件      →    5〜15万 / 月
              ────────────────         ────────────────
              受注のための商品          事業の本体
              利益率は高くない          ここで生きる
```

**KGI：月額運用の月次売上（MRR）**
制作売上は変動する。MRRが固定費を超えた時点でこの事業は「潰れない」状態になる。

### 3年の形

| | 1年目 | 2年目 | 3年目 |
|---|---|---|---|
| 制作受注 | 6〜8件 | 12件 | 15件 |
| 期末MRR | 25万 | 70万 | 130万 |
| 年商目安 | 700〜900万 | 1,800万 | 3,000万 |
| 体制 | 1人 + 外注 | +1人 | +2人 |

※ この数字は**仮置き**。アドバイザーの稼働可能時間と初期資金が確定したら引き直す。

## 4. コスト構造（1人体制・初年度）

| 項目 | 年額 | 備考 |
|---|---|---|
| 法人設立 | 10万 | 合同会社。株式会社（25万）は後から組織変更可 |
| ツール類 | 30万 | Figma / Adobe / Google Workspace / 会計 / ホスティング |
| 営業費 | 50万 | DM印刷・郵送、名刺、交通費、展示会視察 |
| 外注費 | 売上の15〜20% | デザイン・写真撮影・特殊実装のみ |
| **固定費** | **月8〜10万** | 人件費（生活費）を除く |

→ **MRR 10万を超えた時点で会社としては赤字にならない。** 月額2万の顧客なら5社、月額5万なら2社。ここが最初の生存ラインで、90日ロードマップの目標地点。

## 5. 営業チャネル（優先順）

| 順位 | チャネル | 立ち上がり | コメント |
|---|---|---|---|
| 1 | **既存人脈・紹介** | 即 | 最初の実績3件はここで作る。無償/原価でもよい |
| 2 | **制作会社からの下請け** | 1ヶ月 | 営業コストゼロでキャッシュを確保。元請け化するまでの血液 |
| 3 | **業種特化アウトバウンド（手紙＋電話）** | 2〜3ヶ月 | 製造業はメールを見ない。社長宛の封書が効く |
| 4 | 商工会議所 / 業界団体 / 展示会 | 3〜6ヶ月 | 信用の獲得。補助金案件の入口 |
| 5 | 自社サイトSEO / 事例コンテンツ | 6〜12ヶ月 | 遅効性。だが最終的に一番効く |
| — | リスティング広告 | 後回し | 初期はCPAが合わない。MRRが立ってから |
| — | クラウドソーシング | 原則使わない | 単価が崩れ実績にもならない。実績ゼロ期の緊急手段のみ |

## 6. 補助金

製造業向けは**小規模事業者持続化補助金**（販路開拓、Webサイト制作が対象／上限50〜200万）が実質的な営業ツールになる。
「補助金の申請書類までこちらで支援します」は、中小製造業に対して極めて強い提案になる。申請サポートを商品に組み込む方針を提案する。

## 7. 今の最大リスク

1. **実行主体の不在** — 契約・入金・商談は人間側でしか実行できない。アドバイザーの稼働可能時間がこの事業の上限を決める。→ 最優先の確認事項
2. **キャッシュが尽きる** — 元請け案件は初回入金まで2〜4ヶ月かかる。下請けで繋ぐ設計を初月から並走させる
3. **実績ゼロ** — 最初の3件をどう作るかが全て。ここで詰まるなら他の計画は意味がない
