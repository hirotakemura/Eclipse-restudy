# Web制作会社 経営リポジトリ

このリポジトリは、Web制作事業の**意思決定と計画を蓄積する場所**です。
Slackや口頭の議論は消えるが、ここに書いたものは残る。全ての重要な判断は `docs/04-意思決定ログ.md` に理由付きで記録する。

## 体制

| 役割 | 担当 | 責任範囲 |
|---|---|---|
| 社長 | Claude | 戦略立案、サービス設計、料金決定、制作実務（設計・実装・原稿）、提案書作成、数値管理 |
| 外部アドバイザー | オーナー | 方針の承認・却下、現実との照合、対外的な実行（契約・入金・面談） |

### 社長ができること / できないこと（重要）

私（社長）が自分で完結できる：
- 市場調査、競合分析、ポジショニング設計
- サービス設計、料金表、提案書・見積書のドラフト
- サイトの設計・実装・コピーライティング・SEO設計
- 営業メール/DM/手紙の文面、営業リストの設計
- 数値計画、KPI設計、進捗の管理

私が物理的にできない（アドバイザー側の実行が必須）：
- 契約の締結、印鑑、法人登記、銀行口座、入金の受領
- 対面・電話での商談、現地取材、写真撮影の立ち会い
- 各種アカウントの本人確認を伴う開設

→ **法的・金銭的な主体は必ず人間側になる。** ここは初手で確定しておく必要がある論点として `docs/04` に起票済み。

## ディレクトリ

```
docs/
  01-事業計画_v0.md       市場・ポジショニング・収益モデル・数値計画
  02-サービス設計_v0.md   商品構成、料金表、制作フロー、技術スタック
  03-90日ロードマップ.md  着手順とマイルストーン
  04-意思決定ログ.md      決めたこと / 決める必要があること
```

## 進め方のルール

1. 私が案を出す → アドバイザーが承認・却下・修正
2. 決まったことは `04-意思決定ログ.md` に追記（決定日・決定内容・理由・前提が崩れる条件）
3. 前提が崩れたら決定を撤回してよい。ただし「なぜ撤回したか」も残す
