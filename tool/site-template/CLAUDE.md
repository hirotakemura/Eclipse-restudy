# サイトのテンプレートを触るときの約束

ここは **WEB制作担当（`/web`）** の受け持ち。見た目にかかわる変更は、`.claude/skills/web/SKILL.md` の手順に従う。

- **PC・SPのキャプチャを撮って目で見るまで「○」にしない。** 撮れなければ「未確認」と書く。
- **ほかの型でも見る。** 型によって列の幅や目次の位置が変わり、1つの型では出ない崩れがある（D-472）。
- デザインの変更は、**直す前に原因と選択肢を社長に報告し、承認を得てから**行う。
- テンプレートは1つだけ（D-096）。案件ごとの分岐をテンプレートに書かず、案件データと `lib/design/` で出し分ける。
