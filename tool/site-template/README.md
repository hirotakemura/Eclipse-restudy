# サイトテンプレート（製造業向け）

KOBOで聞き取った案件データから、静的サイトを書き出します。

```
cd tool
npm run build:site -- matsubara-seiki        # projects/matsubara-seiki/site/ に書き出す
npm run build:site -- matsubara-seiki --draft # 公開できない状態でも、確認用に残す
npm run dev:site   -- matsubara-seiki        # ブラウザで見ながら直す
```

初回だけ、テンプレートの依存（Astro）を取りに行きます。数分かかります。

## 作りの前提

| | |
|---|---|
| **テンプレートは1つだけ** | 案件ごとにコードを分けた時点で、保守工数がサイト数に比例する。それでは週15時間の運転で回らない（docs/10） |
| **表と一覧は生成しない** | 会社概要・対応可能範囲・設備一覧は、聞き取ったデータをそのまま出す。生成を通せば、通した分だけ捏造の余地が生まれる（D-095） |
| **原稿が無くてもサイトは建つ** | 原稿は散文を足すもので、骨格ではない。生成前でも構成を確認できる |
| **写真が無くても成立する** | 現場写真は取材時点で揃わないことが多い。写真待ちで公開を止めない |
| **電話番号を全ページに置く** | 中小製造業の担当者は電話を使う。フォームだけに依存させない（D-060） |

## 書き出す前に止まる場合

次のときは書き出しを消して止まります（`--draft` で確認用に残せます）。

- ページに `{{要確認}}` が残っている
- 未確認欄に控えた発言が出ている
- 会社名・電話番号・所在地・問い合わせ先メールのどれかが埋まっていない

**KOBOで該当項目を埋めてから、もう一度実行してください。**

## ファイル

```
src/site-data/      build:site が案件データを置く（顧客の情報。コミットしない）
src/lib/site.ts     データの読み込みと、公開してよい値だけにする処理
src/lib/draft.ts    生成した原稿の読み込み
src/layouts/        全ページ共通の枠
src/pages/          ページ
src/styles/site.css 見た目
```
