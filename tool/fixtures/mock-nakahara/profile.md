# 第2のモック案件：有限会社 中原設備（汎用ベーシック）

**架空の会社です。** 汎用ベーシック（198,000円）のテンプレートを検証するために作りました。
製造業のモック（松原精機）と同じ役割を、業種を問わない商品のほうで果たします。

| | |
|---|---|
| 業種 | 住宅の水まわりの設備工事 |
| 所在地 | 北九州市小倉南区 |
| 規模 | 4名（社長・職人2・事務1）／創業1988年 |
| 現状 | **サイトを持っていない**（汎用ベーシックの主な対象） |
| サイトの役割 | 集客・選別・信用構築 |

## なぜこの業種にしたか

1. **サイトを持っていない零細企業**という、汎用商品の実際の対象に近い
2. **「選別」が効く**（遠方の一見客からの値段だけの電話を減らしたい）という、はっきりした動機がある
3. 製造業と違い、**価格を出すかどうかが論点になる**。汎用商品ではここが毎回問題になる

## 仕込んである論点

| # | 内容 | 何を試すか |
|---|---|---|
| 1 | リフォームの価格が「ものによる」としか言われない | **価格を書けない項目**の扱い。「応相談」で出すか、出さないか |
| 2 | 「すぐ来てくれる」の理由が、掘るまで出てこない | 追い質問。**在庫を事務所に置いているから1時間以内**という中身は、定型質問では出ない |
| 3 | 事例の結果に `{{要確認}}` が残っている | 生成を通さない経路でも、マーカーがページに出ないか（D-097・D-112） |
| 4 | 写真が1枚もない | **写真ゼロでもサイトが成立するか**（D-099） |
| 5 | 他社（大手リフォーム会社）の見積額が事例に出てくる | 出せない情報（NG）の線引き。**社名は出さない**が、金額の比較は書いてよいか |

## 検証結果（2026-09-13）

- 7ページを書き出し（製造業は13ページ）。**対応可能範囲・設備一覧・事例の個別ページは作られない**
- 写真ゼロでも崩れない
- `{{要確認}}` はページに出ない
- **見つかった不具合**：問い合わせの誘い文句が「図面をお持ちでしたら」のままだった（D-136で修正）
